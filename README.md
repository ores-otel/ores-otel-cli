# ores-otel-cli

Rust CLI for Logging, telemetry, and observability for ORESoftware runtimes. Uses flags-2-env via `.cli-flags.toml`. Talks to `ores-otel-api-server.rs`.
Env keys are generated by `f2e generate` from `.cli-flags.toml` into `generated/{rust,dart,typescript,gleam}`.

## Telemetry

The CLI logs through `oresoftware-next-loggers` (`src/telemetry.rs`). stdout stays command output;
records are written to stderr as `next-loggers/v1` JSON lines. Failures are logged at error level
with the error class and exit code only. Dispatch and command completion are logged at debug and
are filtered at the default level. Every call site carries an inline `ores-trace-…` literal, and
each function declares one `ores-routine-…` ID at its top (see
[ores.otel.log docs](https://github.com/ores-otel/ores.otel.log/blob/main/docs/ores-trace-and-routine-ids.md)).
Argv, flag values, API base URLs, and error messages are never logged.
